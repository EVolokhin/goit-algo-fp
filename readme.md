# Фінальне завдання: метод Монте-Карло
## Мета та методика

Програма `Task_7.py` імітує 1 000 000 кидків двох чесних шестигранних кубиків. Для відтворюваності використано `seed=42`. Під час кожного кидка генеруються два числа від 1 до 6, обчислюється їхня сума та збільшується відповідний лічильник.

Запуск програми:

```bash
python Task_7.py
```

## Висновки щодо правильності розрахунків

Отримані методом Монте-Карло ймовірності близькі до аналітичних для всіх сум. Максимальне абсолютне відхилення становить **0.0433 відсоткового пункта** для суми 8. 
Найчастіше спостерігається сума **7**: експериментальна ймовірність 16.6297% порівняно з аналітичною 16.6667%. Найрідше випадають суми **2 і 12**, ймовірності яких близькі до 2.7778%. 
Зі збільшенням кількості кидків типова похибка зменшується приблизно як `1/sqrt(N)`, хоча в окремому запуску відхилення може збільшитися.
